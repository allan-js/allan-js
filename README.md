# Hi there 👋, I am Allan

I build stuff from electronics, mechanical systems, to computer software.

## 🔭 I’m currently working on:
   
1. **GEPA Systems 🌱:** A compact, modular and scalable Irrigation Automation Computer (called WEM-C). It is easy to use and affordable for a small farmer in Africa or any third-world Country. It enables him/her to automate his/her irrigation with as much precision as a large-scale farmer in Europe would.
   [www.gepa.gu.ac.ug](https://gepa.gu.ac.ug/)
